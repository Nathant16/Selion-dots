# Sway — Руководство и горячие клавиши

Sway — эталонный i3-совместимый тайловый Wayland-композитор на базе wlroots с минимальным потреблением системных ресурсов и максимальной надежностью.

Все базовые системные комбинации (запуск Kitty, Ski, Btop, лаунчера, скриншотов, мультимедиа и переключения раскладки) работают так же, как и в остальных композиторах. Их полный список см. в [общем руководстве по горячим клавишам](../README.md).

---

## Концепция и ключевые особенности

- **Ручной тайлинг (дерево i3):** Окна организуются в логическое дерево контейнеров. Пользователь сам определяет направление разделения (по горизонтали, вертикали, вкладками или стеком).
- **Карман (Scratchpad):** Специальное скрытое пространство (`Super + S` / `Super + Alt + S`), куда можно свернуть любое окно и вызвать его поверх остальных по одной клавише.
- **Жесты тачпада:** Поддержка трехпальцевых свайпов для переключения рабочих столов и открытия лаунчера.
- **Режим Clamshell:** При закрытии крышки ноутбука с подключенным внешним монитором экран ноутбука автоматически гаснет, а внешний монитор становится основным.

## Горячие клавиши Sway

Основная клавиша-модификатор: `Super` (Win).

### Управление окнами
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + Q` | `kill` | Закрыть активное окно |
| `Alt + Enter` | `fullscreen toggle` | Полноэкранный режим |
| `Super + Space` | `floating toggle` | Переключить плавающий / тайловый режим |
| `Super + S` / `Super + Backspace` | `scratchpad show` | Показать / скрыть окно из Scratchpad |
| `Super + Alt + S` | `move scratchpad` | Отправить активное окно в Scratchpad |

### Фокус, перемещение и изменение размера
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + Стрелки` | `focus left/right/up/down` | Переместить фокус по направлению |
| `Alt + Tab` | `focus next` | Фокус на следующее окно |
| `Alt + Shift + Tab` | `focus prev` | Фокус на предыдущее окно |
| `Super + Alt + Стрелки` | `move left/right/up/down` | Переместить тайловое окно в направлении |
| `Super + Shift + Вправо` | `resize grow width 5 ppt` | Увеличить ширину окна на 5% |
| `Super + Shift + Влево` | `resize shrink width 5 ppt` | Уменьшить ширину окна на 5% |
| `Super + Shift + Вниз` | `resize grow height 5 ppt` | Увеличить высоту окна на 5% |
| `Super + Shift + Вверх` | `resize shrink height 5 ppt` | Уменьшить высоту окна на 5% |
| `Super + ЛКМ` (зажать) | `floating move` | Перетаскивание плавающего окна мышью |
| `Super + ПКМ` (зажать) | `floating resize` | Изменение размера плавающего окна мышью |

### Рабочие столы (Воркспейсы 1..10)
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + 1..0` | `workspace <N>` | Переключиться на рабочий стол 1..10 |
| `Super + Shift + 1..0` | `move to workspace <N>` | Переместить окно на рабочий стол 1..10 |
| `Super + Ctrl + Влево/Вправо` | `workspace prev/next` | Предыдущий / следующий рабочий стол |
| `Super + Ctrl + Вверх/Вниз` | `workspace prev/next` | Предыдущий / следующий рабочий стол |

### Жесты тачпада
| Жест | Действие |
| :--- | :--- |
| **Свайп 3 пальцами влево** | Переключиться на следующий рабочий стол (`workspace next`) |
| **Свайп 3 пальцами вправо** | Переключиться на предыдущий рабочий стол (`workspace prev`) |
| **Свайп 3 пальцами вверх** | Открыть меню приложений (Лаунчер Serpantinum) |
