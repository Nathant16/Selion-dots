# Sway — Руководство и горячие клавиши

**Sway** — эталонный, быстрый и проверенный временем i3-совместимый тайловый Wayland-композитор на базе `wlroots`. В Selion он полностью интегрирован со сквозной темой оформления, статус-баром Serpantinum, меню приложений и единым набором горячих клавиш.

---

## 🧭 Концепция и ключевые особенности

- **Ручной тайлинг (i3-дерево):** Окна организуются в логическое дерево контейнеров. Вы сами определяете, как делить пространство (по горизонтали, вертикали, вкладками или стеком).
- **Максимальная стабильность:** Sway является старейшим и наиболее зрелым Wayland-композитором с минимальным потреблением ресурсов.
- **Scratchpad (Карман):** Специальное скрытое пространство (`Super + S` / `Super + Alt + S`), куда можно спрятать любое окно (мессенджер, музыкальный плеер, терминал) и мгновенно вызвать его поверх всех окон по одной клавише.
- **Жесты тачпада:** Поддержка трехпальцевых свайпов для переключения рабочих столов и открытия лаунчера приложений.

## ⌨️ Таблица горячих клавиш

Основная клавиша-модификатор: **`Super` (Win)**.

### 🪟 Управление окнами
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + Q` | `kill` | Закрыть активное окно |
| `Alt + Enter` | `fullscreen toggle` | Полноэкранный режим |
| `Super + Space` | `floating toggle` | Переключить плавающий / тайловый режим |
| `Super + S` / `Super + Backspace` | `scratchpad show` | Показать / скрыть окно из Scratchpad (кармана) |
| `Super + Alt + S` | `move scratchpad` | Отправить активное окно в Scratchpad |

### 🧭 Фокус и навигация
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + Стрелки` | `focus left/right/up/down` | Переместить фокус по направлению стрелок |
| `Alt + Tab` | `focus next` | Фокус на следующее окно |
| `Alt + Shift + Tab` | `focus prev` | Фокус на предыдущее окно |

### 📐 Перемещение и изменение размера окон
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + Alt + Стрелки` | `move left/right/up/down` | Переместить тайловое окно в направлении |
| `Super + Shift + Вправо` | `resize grow width 5 ppt` | Увеличить ширину окна |
| `Super + Shift + Влево` | `resize shrink width 5 ppt` | Уменьшить ширину окна |
| `Super + Shift + Вниз` | `resize grow height 5 ppt` | Увеличить высоту окна |
| `Super + Shift + Вверх` | `resize shrink height 5 ppt` | Уменьшить высоту окна |
| `Super + ЛКМ` (зажать) | `floating move` | Перетаскивание плавающего окна мышью |
| `Super + ПКМ` (зажать) | `floating resize` | Изменение размера плавающего окна мышью |

### 🖥️ Рабочие столы (Воркспейсы 1..10)
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + 1..0` | `workspace <N>` | Переключиться на рабочий стол 1..10 |
| `Super + Shift + 1..0` | `move to workspace <N>` | Переместить окно на рабочий стол 1..10 |
| `Super + Ctrl + Влево/Вправо` | `workspace prev/next` | Предыдущий / следующий рабочий стол |
| `Super + Ctrl + Вверх/Вниз` | `workspace prev/next` | Предыдущий / следующий рабочий стол |

### 🖐️ Жесты тачпада
| Жест | Действие |
| :--- | :--- |
| **Свайп 3 пальцами влево** | Переключиться на следующий рабочий стол (`workspace next`) |
| **Свайп 3 пальцами вправо** | Переключиться на предыдущий рабочий стол (`workspace prev`) |
| **Свайп 3 пальцами вверх** | Открыть меню приложений (Лаунчер Serpantinum) |

### 🚀 Приложения и оболочка Selion
| Комбинация | Действие |
| :--- | :--- |
| `Super + Enter` | Терминал Kitty |
| `Super + E` | Файловый менеджер Ski |
| `Ctrl + Shift + Esc` / `Ctrl + Alt + Del` | Системный монитор Btop |
| `Super + A` | Меню приложений (лаунчер) |
| `Super + I` | Панель настроек Selion |
| `Super + V` | История буфера обмена |
| `Super + W` | Меню выбора обоев |
| `Super + B` | Скрыть/показать статус-бар |
| `Super + R` | Перезагрузить оболочку Serpantinum |
| `Super + L` | Блокировка экрана |
| `Print` | Скриншот выбранной области |
| `Shift + Print` | Скриншот области с редактором (Satty) |
| `Super + Print` | Скриншот всего экрана |

| Мультимедиа-клавиши | Громкость, микрофон, яркость экрана, медиаплеер |

## 💡 Полезные настройки

- Файлы конфигурации Sway находятся в [compositors/sway/default/](file:///media/Drives/Windows-D/Projects/Selion/Selion-dots/compositors/sway/default/).
- Пользовательские переопределения вносите в [compositors/sway/userprefs](file:///media/Drives/Windows-D/Projects/Selion/Selion-dots/compositors/sway/userprefs) — этот файл никогда не затирается обновлениями.
- При закрытии крышки ноутбука с подключенным внешним монитором Sway автоматически активирует режим Clamshell (экран ноутбука выключается, внешний монитор становится основным).
