# Hyprland — Руководство и горячие клавиши

Hyprland — динамический тайловый Wayland-композитор на базе библиотеки wlroots с поддержкой физических анимаций, закругленных углов, эффектов матового стекла (blur) и управления жестами.

Все базовые системные комбинации (запуск Kitty, Ski, Btop, лаунчера, скриншотов, мультимедиа и переключения раскладки) работают так же, как и в остальных композиторах. Их полный список см. в [общем руководстве по горячим клавишам](../README.md).

---

## Концепция и ключевые особенности

- **Автоматический динамический тайлинг (Dwindle / Master):** Окна автоматически распределяются по экрану с оптимальным использованием площади.
- **Интерактивные жесты тачпада:** Свайп тремя пальцами плавно (1:1) тянет рабочий стол следом за рукой.
- **Плавающие окна:** Любое окно переключается в плавающий режим комбинацией `Super + Space`.
- **Специальный рабочий стол (Scratchpad):** Всплывающее скрытое пространство (`Super + S`) для заметок, терминала или мессенджера.

## Горячие клавиши Hyprland

Основная клавиша-модификатор: `Super` (Win).

### Управление окнами
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + Q` | `killactive` | Закрыть активное окно |
| `Super + K` | `kill` | Принудительно завершить процесс окна |
| `Alt + Enter` | `fullscreen` | Полноэкранный режим |
| `Super + Space` | `togglefloating` | Переключить плавающий / тайловый режим |
| `Super + Alt + F` | `fullscreen (maximized)` | Максимизировать окно без скрытия панелей |
| `Super + S` | `togglespecialworkspace` | Показать / скрыть Scratchpad |
| `Super + Alt + S` | `movetoworkspace special` | Отправить активное окно в Scratchpad |

### Фокус, перемещение и изменение размера
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + Стрелки` | `focus` | Переместить фокус (влево / вправо / вверх / вниз) |
| `Alt + Tab` | `cyclenext` | Переключить фокус на следующее окно |
| `Super + Alt + Стрелки` | `movewindow` | Переместить тайловое окно в направлении стрелки |
| `Super + Shift + Стрелки` | `resizewindow` | Изменить размер активного окна с шагом 40px |
| `Super + ЛКМ` (зажать) | `movewindow` | Плавное перетаскивание окна мышью |
| `Super + ПКМ` (зажать) | `resizewindow` | Плавное изменение размера окна мышью |

### Рабочие столы (Воркспейсы 1..10)
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + 1..0` | `workspace <N>` | Переключиться на рабочий стол 1..10 |
| `Super + Shift + 1..0` | `movetoworkspace <N>` | Переместить активное окно на рабочий стол 1..10 |
| `Super + Ctrl + Влево/Вправо` | `workspace r-1 / r+1` | Предыдущий / следующий рабочий стол |
| `Super + Колесико мыши` | `workspace e±1` | Быстрое листание рабочих столов |
| **Свайп 3 пальцами** | `workspace_swipe` | Плавное 1:1 перелистывание столов тачпадом |
