# Hyprland — Руководство и горячие клавиши

**Hyprland** — динамический тайловый Wayland-композитор на основе библиотеки `wlroots` с поддержкой плавных физических анимаций, закруглённых углов, эффектов матового стекла (blur), кастомных плагинов и удобного управления окнами.

---

## 🧭 Концепция и ключевые особенности

- **Автоматический динамический тайлинг (Dwindle / Master):** Окна автоматически распределяются по экрану с оптимальным использованием пространства.
- **Интерактивные жесты тачпада:** Свайп 3 пальцами плавно (1:1) тянет виртуальный рабочий стол следом за рукой.
- **Плавающие окна и Picture-in-Picture:** Любое окно можно перевести в плавающий режим (`Super + Space`) или закрепить в углу экрана.
- **Специальный рабочий стол (Scratchpad):** Всплывающее скрытое пространство (`Super + S`) для заметок, терминала или мессенджера.

## ⌨️ Таблица горячих клавиш

Основная клавиша-модификатор: **`Super` (Win)**.

### 🪟 Управление окнами
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + Q` | `killactive` | Закрыть активное окно |
| `Super + K` | `kill` | Принудительно завершить процесс окна |
| `Alt + Enter` | `fullscreen` | Полноэкранный режим |
| `Super + Space` | `togglefloating` | Переключить плавающий / тайловый режим |
| `Super + Alt + F` | `fullscreen (maximized)` | Максимизировать окно без скрытия рамок |
| `Super + S` | `togglespecialworkspace` | Показать / скрыть специальный воркспейс (Scratchpad) |
| `Super + Alt + S` | `movetoworkspace special` | Отправить окно в специальный воркспейс |

### 🧭 Фокус и навигация
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + Стрелки` | `focus` | Переместить фокус (влево / вправо / вверх / вниз) |
| `Alt + Tab` | `cyclenext` | Переключить фокус на следующее окно |

### 📐 Перемещение и изменение размера окон
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + Alt + Стрелки` | `movewindow` | Переместить тайловое окно в направлении |
| `Super + Shift + Стрелки` | `resizewindow` | Изменить размер активного окна на 40px |
| `Super + ЛКМ` (зажать) | `movewindow` | Плавное перетаскивание окна мышью |
| `Super + ПКМ` (зажать) | `resizewindow` | Плавное изменение размера окна мышью |

### 🖥️ Рабочие столы (Воркспейсы 1..10)
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + 1..0` | `workspace <N>` | Переключиться на рабочий стол 1..10 |
| `Super + Shift + 1..0` | `movetoworkspace <N>` | Переместить активное окно на рабочий стол 1..10 |
| `Super + Ctrl + Влево/Вправо` | `workspace r-1 / r+1` | Предыдущий / следующий рабочий стол |
| `Super + Колёсико мыши` | `workspace e±1` | Быстрое листание столов колесом |
| **Свайп тремя пальцами** | `workspace_swipe` | Плавное 1:1 перелистывание столов тачпадом |

### 🚀 Приложения и оболочка Selion
| Комбинация | Действие |
| :--- | :--- |
| `Super + Enter` | Терминал Kitty |
| `Super + E` | Файловый менеджер Ski |
| `Ctrl + Shift + Esc` / `Ctrl + Alt + Del` | Системный монитор Btop |
| `Super + A` | Меню приложений (лаунчер) |
| `Super + I` | Панель настроек Selion |
| `Super + V` | История буфера обмена |
| `Super + W` | Меню выбора обоев |
| `Super + B` | Скрыть/показать статус-бар |
| `Super + R` | Перезагрузить оболочку Serpantinum |
| `Super + L` | Блокировка экрана |
| `Print` | Скриншот выбранной области |
| `Shift + Print` | Скриншот области с редактором (Satty) |
| `Super + Print` | Скриншот всего экрана |
| `Super + Shift + Print` | Скриншот всего экрана с редактором |
| `Alt + Shift` / `Ctrl + Shift` | Переключение раскладки клавиатуры |
| `Super + Shift + C/Z/S/T/G/D/O` | VS Code, Zen Browser, Spotify, AyuGram, Steam, Discord, Obsidian |
| Мультимедиа-клавиши | Громкость, микрофон, яркость экрана, медиаплеер |
