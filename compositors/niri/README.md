# Niri — Руководство и горячие клавиши

**Niri** — современный бесконечно-прокручиваемый тайловый Wayland-композитор (*scrollable-tiling compositor*). Окна в Niri не сжимаются до микроскопических размеров при открытии новых программ, а выстраиваются в бесконечную горизонтальную ленту колонок, по которой можно плавно перемещаться.

---

## 🧭 Концепция и ключевые особенности

- **Бесконечная лента колонок:** Каждое окно или группа окон занимает колонку фиксированной удобной ширины. Экран — это «видоискатель», скользящий вдоль ленты.
- **Обзор всех окон (Overview):** Клавиша `Super + S` или `Super + Backspace` плавно отдаляет камеру, показывая миниатюры всех открытых колонок на текущем рабочем столе.
- **Интуитивная работа с тачпадом:** Горизонтальный скролл двумя пальцами плавно прокручивает ленту окон в реальном времени.
- **Вертикальные рабочие столы:** В отличие от классических горизонтальных столов, в Niri рабочие столы переключаются вертикально (вверх/вниз).
- **Плавающий режим:** Окна настроек или утилит можно открепить от ленты и сделать свободно парящими (`Super + Space`).

## ⌨️ Таблица горячих клавиш

Основная клавиша-модификатор: **`Super` (Win)**.

### 🪟 Управление окнами
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + Q` | `close-window` | Закрыть активное окно |
| `Alt + Enter` / `Super + Alt + F` | `maximize-window-to-edges` | Распахнуть окно на всю видимую область экрана |
| `Super + Space` | `toggle-window-floating` | Переключить плавающий / ленточный режим |
| `Super + S` / `Super + Backspace` | `toggle-overview` | Режим обзора всех колонок (Overview) |

### 🧭 Фокус и навигация
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + Влево/Вправо` | `focus-column-left/right` | Переместить фокус на соседнюю колонку ленты |
| `Super + Вверх/Вниз` | `focus-window-or-workspace` | Переместить фокус внутри колонки / на стол |
| `Alt + Tab` | `focus-window-down` | Переключить фокус на следующее окно |

### 📐 Перемещение колонок и изменение размеров
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + Alt + Влево/Вправо` | `move-column-left/right` | Сдвинуть текущую колонку влево или вправо по ленте |
| `Super + Alt + Вверх/Вниз` | `move-window-up/down` | Переместить окно внутри колонки вверх или вниз |
| `Super + Shift + Влево/Вправо` | `set-column-width ±5%` | Изменить ширину активной колонки |
| `Super + Shift + Вверх/Вниз` | `set-window-height ±5%` | Изменить высоту окна внутри колонки |

### 🖥️ Рабочие столы (Воркспейсы 1..10)
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + 1..0` | `workspace <N>` | Переключиться на рабочий стол 1..10 |
| `Super + Shift + 1..0` | `move to workspace <N>` | Переместить колонку на рабочий стол 1..10 |
| `Super + Ctrl + Влево/Вверх` | `focus-workspace-up` | Переключиться на рабочий стол выше |
| `Super + Ctrl + Вправо/Вниз` | `focus-workspace-down` | Переключиться на рабочий стол ниже |

### 🖐️ Тачпад и мышь
| Действие | Описание |
| :--- | :--- |
| **Скролл двумя пальцами по горизонтали** | Плавное прокручивание ленты окон |
| `Super + ЛКМ` (зажать) | Перетаскивание плавающего окна |
| `Super + ПКМ` (зажать) | Изменение размера плавающего окна |

### 🚀 Приложения и оболочка Selion
| Комбинация | Действие |
| :--- | :--- |
| `Super + Enter` | Терминал Kitty |
| `Super + E` | Файловый менеджер Ski |
| `Ctrl + Shift + Esc` / `Ctrl + Alt + Del` | Системный монитор Btop |
| `Super + A` | Меню приложений (лаунчер) |
| `Super + I` | Панель настроек Selion |
| `Super + V` | История буфера обмена |
| `Super + W` | Меню выбора обоев |
| `Super + B` | Скрыть/показать статус-бар |
| `Super + R` | Перезагрузить оболочку Serpantinum |
| `Super + L` | Блокировка экрана |
| `Print` | Скриншот выбранной области |
| `Shift + Print` | Скриншот области с редактором (Satty) |
| `Super + Print` | Скриншот всего экрана |
| `Super + Shift + Print` | Скриншот всего экрана с редактором |
| `Alt + Shift` / `Ctrl + Shift` | Переключение раскладки клавиатуры |
| `Super + Shift + C/Z/S/T/G/D/O` | VS Code, Zen Browser, Spotify, AyuGram, Steam, Discord, Obsidian |
| Мультимедиа-клавиши | Громкость, микрофон, яркость экрана, медиаплеер |

## 💡 Полезные настройки

- Файлы конфигурации Niri находятся в [compositors/niri/default/](file:///media/Drives/Windows-D/Projects/Selion/Selion-dots/compositors/niri/default/).
- Пользовательские переопределения вносите в [compositors/niri/userprefs.kdl](file:///media/Drives/Windows-D/Projects/Selion/Selion-dots/compositors/niri/userprefs.kdl).
- В Niri очень удобно держать браузер шириной 60–70% экрана, а рядом в соседней колонке редактор кода — переключение между ними происходит моментально по `Super + Влево/Вправо`.
