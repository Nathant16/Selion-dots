# Niri — Руководство и горячие клавиши

Niri — бесконечно-прокручиваемый тайловый Wayland-композитор (scrollable-tiling compositor). Окна в Niri выстраиваются в горизонтальную ленту колонок, по которой можно плавно перемещаться, сохраняя комфортный размер каждого окна.

Все базовые системные комбинации (запуск Kitty, Ski, Btop, лаунчера, скриншотов, мультимедиа и переключения раскладки) работают так же, как и в остальных композиторах. Их полный список см. в [общем руководстве по горячим клавишам](../README.md).

---

## Концепция и ключевые особенности

- **Бесконечная лента колонок:** Каждое окно занимает колонку удобной ширины. Экран выступает в роли видоискателя, скользящего вдоль ленты.
- **Обзор всех окон (Overview):** Клавиша `Super + S` или `Super + Backspace` отдаляет камеру, показывая миниатюры всех открытых колонок на текущем рабочем столе.
- **Тачпад:** Горизонтальный скролл двумя пальцами плавно прокручивает ленту окон в реальном времени.
- **Вертикальные рабочие столы:** Рабочие столы в Niri переключаются вертикально (вверх/вниз).

## Горячие клавиши Niri

Основная клавиша-модификатор: `Super` (Win).

### Управление окнами
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + Q` | `close-window` | Закрыть активное окно |
| `Alt + Enter` / `Super + Alt + F` | `maximize-window-to-edges` | Распахнуть окно на всю видимую область экрана |
| `Super + Space` | `toggle-window-floating` | Переключить плавающий / ленточный режим |
| `Super + S` / `Super + Backspace` | `toggle-overview` | Режим обзора всех колонок (Overview) |

### Фокус, перемещение колонок и размеры
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + Влево/Вправо` | `focus-column-left/right` | Переместить фокус на соседнюю колонку ленты |
| `Super + Вверх/Вниз` | `focus-window-or-workspace` | Переместить фокус внутри колонки / на стол |
| `Alt + Tab` | `focus-window-down` | Переключить фокус на следующее окно |
| `Super + Alt + Влево/Вправо` | `move-column-left/right` | Сдвинуть текущую колонку влево или вправо по ленте |
| `Super + Alt + Вверх/Вниз` | `move-window-up/down` | Переместить окно внутри колонки вверх или вниз |
| `Super + Shift + Влево/Вправо` | `set-column-width ±5%` | Изменить ширину активной колонки на 5% |
| `Super + Shift + Вверх/Вниз` | `set-window-height ±5%` | Изменить высоту окна внутри колонки на 5% |

### Рабочие столы (Воркспейсы 1..10)
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + 1..0` | `workspace <N>` | Переключиться на рабочий стол 1..10 |
| `Super + Shift + 1..0` | `move to workspace <N>` | Переместить колонку на рабочий стол 1..10 |
| `Super + Ctrl + Влево/Вверх` | `focus-workspace-up` | Переключиться на рабочий стол выше |
| `Super + Ctrl + Вправо/Вниз` | `focus-workspace-down` | Переключиться на рабочий стол ниже |

### Тачпад и мышь
| Действие | Описание |
| :--- | :--- |
| **Скролл двумя пальцами по горизонтали** | Плавное перемещение ленты окон |
| `Super + ЛКМ` (зажать) | Перетаскивание плавающего окна |
| `Super + ПКМ` (зажать) | Изменение размера плавающего окна |
