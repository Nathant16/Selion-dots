# DriftWM — Руководство и горячие клавиши

**DriftWM** — инновационный Wayland-композитор с концепцией **бесконечного 2D-холста** (*infinite canvas*), оптимизированный для комфортной работы с тачпадом и свободным расположением окон на огромном виртуальном полотне (по аналогии с досками в Miro или Figma).

---

## 🧭 Концепция и ключевые особенности

- **Бесконечный холст:** Окна не принуждаются к жесткой тайловой сетке, а свободно живут на бесконечной плоскости.
- **Свободный зум:** Камеру можно отдалить, чтобы увидеть весь рабочий процесс целиком, или приблизить к конкретной задаче.
- **Закладки (Bookmarks) вместо обычных столов:** Окна не прячутся при смене «воркспейса». Переключение между столами 1–9 — это плавный перелёт камеры к соответствующим координатам холста.
- **Заморозка окон (`suspend-window`):** Неиспользуемые окна можно отправить в спящий режим: процесс выгружается из памяти, а на холсте остаётся легкая заглушка-карточка.
- **Закрепление на экране (`pinned_to_screen`):** Окно можно «прилепить» к стеклу монитора, и при полетах камеры по холсту оно останется неподвижным (HUD / Picture-in-Picture).
- **Интерактивная карта холста (Canvas Minimap):** При перемещении камеры или зуме в правом нижнем углу плавно и быстро появляется неосязаемый радар, отображающий расположение окон, закладок 1..9 и текущую видимую область экрана пользователя.

## ⌨️ Таблица горячих клавиш

Основная клавиша-модификатор: **`Super` (Win)**.

### 🪟 Управление окнами
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + Q` | `close-window` | Закрыть активное окно |
| `Super + Shift + Q` | `suspend-window` | Усыпить/заморозить окно (освобождает RAM/CPU) |
| `Alt + Enter` | `toggle-fullscreen` | Полноэкранный режим |
| `Super + Space` / `Super + T` | `toggle-pin-to-screen` | Прикрепить к экрану поверх холста |
| `Super + Home` / `Super + ~` | `home-toggle` | Возврат камеры в домашнюю точку (0,0) |

### 🔍 Навигация и фокус
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + Стрелки` | `focus-nearest` | Фокус на ближайшее окно в направлении |
| `Alt + Tab` | `cycle-windows forward` | Фокус на следующее окно |
| `Alt + Shift + Tab` | `cycle-windows backward` | Фокус на предыдущее окно |

### 📐 Перемещение и изменение размера
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + Alt + Стрелки` | `move-to-snap` | Переместить окно со снаппингом к соседним окнам |
| `Super + Shift + Вправо` | `grow-window right` | Увеличить ширину окна вправо |
| `Super + Shift + Влево` | `shrink-window right` | Уменьшить ширину окна справа |
| `Super + Shift + Вниз` | `grow-window down` | Увеличить высоту окна вниз |
| `Super + Shift + Вверх` | `shrink-window down` | Уменьшить высоту окна снизу |

### 🔭 Управление камерой и зумом
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + =` | `zoom-in` | Приблизить камеру холста |
| `Super + -` | `zoom-out` | Отдалить камеру холста |
| `Super + 0` | `zoom-reset` | Сбросить масштаб на 100% (1.0) |
| `Super + Shift + W` | `zoom-to-fit` | Вместить все окна холста в экран |

### 🔖 Закладки камеры (Воркспейсы 1..9)
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + 1..9` | `go-to-bookmark <N>` | Переместить камеру к закладке 1..9 |
| `Super + Ctrl + 1..9` | `set-bookmark <N>` | Сохранить текущие координаты камеры как закладку |
| `Super + Shift + 1..9` | `move-to-bookmark <N>` | Отправить активное окно к закладке 1..9 |
| `Super + Ctrl + Влево/Вправо` | `go-to-bookmark prev/next` | Переместиться к предыдущей / следующей закладке |

### 🖱️ Мышь и тачпад

## 💡 Советы по продуктивности в DriftWM

1. **Организуйте пространство кластерами:**
   - **Закладка 1 (`Super + 1`):** Рабочий терминал и редактор кода.
   - **Закладка 2 (`Super + 2`):** Браузер и документация.
   - **Закладка 3 (`Super + 3`):** Мессенджеры, почта и музыка.
2. **Используйте `suspend-window` для тяжёлых приложений:** Если браузер или IDE временно не нужны, нажмите `Super + Shift + Q` — память освободится, а при клике окно мгновенно вернется в строй.
3. **Обзор всей системы:** Нажмите `Super + Shift + W` или сделайте жест отдаления на тачпаде, чтобы увидеть состояние всех запущенных приложений одним взглядом.
