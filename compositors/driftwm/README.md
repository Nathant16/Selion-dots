# DriftWM — Руководство и горячие клавиши

DriftWM — инновационный Wayland-композитор с концепцией бесконечного 2D-холста (infinite canvas), оптимизированный для комфортной работы с тачпадом и свободным расположением окон на виртуальном полотне (по аналогии с досками в Miro или Figma).

Все базовые системные комбинации (запуск Kitty, Ski, Btop, лаунчера, скриншотов, мультимедиа и переключения раскладки) работают так же, как и в остальных композиторах. Их полный список см. в [общем руководстве по горячим клавишам](../README.md).

---

## Концепция и ключевые особенности

- **Бесконечный холст:** Окна не принуждаются к жесткой тайловой сетке, а свободно размещаются на бесконечной плоскости.
- **Свободный зум:** Камеру можно отдалить для обзора всего рабочего пространства или приблизить к конкретному окну.
- **Закладки (Bookmarks) вместо обычных столов:** Окна не прячутся при смене рабочего пространства. Переключение между столами 1–9 — это плавный перелет камеры к соответствующим координатам холста.
- **Заморозка окон (`suspend-window`):** Неиспользуемые окна можно отправить в спящий режим: процесс выгружается из памяти, а на холсте остается легкая заглушка-карточка. Для оживления окна достаточно кликнуть по нему мышью или нажать `Enter`.
- **Закрепление на экране (`pinned_to_screen`):** Окно можно закрепить поверх холста (режим HUD / Picture-in-Picture). При перемещении камеры оно остается неподвижным относительно экрана.
- **Интерактивная карта холста (Canvas Minimap):** При перемещении камеры в правом нижнем углу плавно появляется неосязаемый радар, отображающий расположение окон, закладок 1..9 и текущую видимую область экрана пользователя.

## Уникальные горячие клавиши DriftWM

Основная клавиша-модификатор: `Super` (Win).

### Управление холстом, зумом и камерой
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + =` | `zoom-in` | Приблизить камеру холста |
| `Super + -` | `zoom-out` | Отдалить камеру холста |
| `Super + 0` | `zoom-reset` | Сбросить масштаб на 100% (1.0) |
| `Super + Shift + W` | `zoom-to-fit` | Вместить все открытые окна холста в экран |
| `Super + Home` / `Super + ~` | `home-toggle` | Мгновенный возврат камеры в домашнюю точку (0, 0) |

### Закладки камеры (Воркспейсы 1..9)
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + 1..9` | `go-to-bookmark <N>` | Переместить камеру к координатам закладки 1..9 |
| `Super + Ctrl + 1..9` | `set-bookmark <N>` | Сохранить текущие координаты и зум камеры в слот закладки |
| `Super + Shift + 1..9` | `move-to-bookmark <N>` | Переместить активное окно к координатам закладки 1..9 |
| `Super + Ctrl + Влево/Вправо` | `go-to-bookmark prev/next` | Переместиться к предыдущей / следующей закладке |

### Управление окнами и размерами
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + Q` | `close-window` | Закрыть активное окно |
| `Super + Shift + Q` | `suspend-window` | Заморозить окно (освободить RAM/CPU) |
| `Alt + Enter` | `toggle-fullscreen` | Полноэкранный режим |
| `Super + Space` / `Super + T` | `toggle-pin-to-screen` | Прикрепить окно к экрану поверх холста (HUD) |
| `Super + Alt + Стрелки` | `move-to-snap` | Переместить окно со снаппингом к соседним окнам |
| `Super + Shift + Вправо` | `grow-window right` | Увеличить ширину окна вправо |
| `Super + Shift + Влево` | `shrink-window right` | Уменьшить ширину окна справа |
| `Super + Shift + Вниз` | `grow-window down` | Увеличить высоту окна вниз |
| `Super + Shift + Вверх` | `shrink-window down` | Уменьшить высоту окна снизу |

### Управление мышью и тачпадом
| Действие | Функция |
| :--- | :--- |
| `Super + ЛКМ` (в любом месте, включая окна) | Панорамирование камеры по холсту |
| `Alt + ЛКМ` (на окне) | Перетаскивание окна по холсту |
| `Alt + ПКМ` (на окне) | Плавное изменение размера окна |
| `СКМ (средняя кнопка / колесико)` | Панорамирование камеры по холсту |
| **Жест щипка (Pinch)** двумя пальцами | Плавный зум холста (приближение / отдаление) |
| **Клик ЛКМ** или **`Enter`** по карточке | Оживить замороженное окно |

## Советы по продуктивности

1. **Организация пространства кластерами:**
   - Закладка 1 (`Super + 1`): рабочий терминал и редактор кода.
   - Закладка 2 (`Super + 2`): браузер и техническая документация.
   - Закладка 3 (`Super + 3`): мессенджеры, почта и музыка.
2. **Заморозка тяжелых задач:** если браузер или IDE временно не нужны, нажмите `Super + Shift + Q` — оперативная память освободится, а при клике окно мгновенно вернется в рабочее состояние.
3. **Обзор холста:** нажмите `Super + Shift + W` или отдалите камеру жестом тачпада, чтобы увидеть расположение всех задач целиком.
4. **Конфигурация:** настройки DriftWM находятся в [compositors/driftwm/config.toml](file:///media/Drives/Windows-D/Projects/Selion/Selion-dots/compositors/driftwm/config.toml).
