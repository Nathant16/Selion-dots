# Mango — Руководство и горячие клавиши

**Mango** — ультра-легковесный, минималистичный динамический тайловый Wayland-композитор на базе `wlroots`, вдохновленный философией `dwm`. Mango потребляет минимум оперативной памяти и ресурсов процессора, обеспечивая максимальную скорость отклика даже на слабых ноутбуках и портативных устройствах.

---

## 🧭 Концепция и ключевые особенности

- **Классический динамический тайлинг (Master & Stack):** Экран разделен на главную область (Master — для основной активной задачи) и стек второстепенных окон (Stack). Новые окна автоматически занимают удобные пропорции.
- **Мгновенный отклик и лёгкость:** Отсутствие тяжелых графических прослоек обеспечивает минимальную задержку ввода.
- **Scratchpad:** Всплывающий скрытый терминал или блокнот по нажатию `Super + S` или `Super + Backspace`.
- **Быстрый обмен окон (Exchange):** Мгновенная перестановка окна в мастер-зону или перемещение по стеку комбинацией `Super + Alt + Стрелки`.

## ⌨️ Таблица горячих клавиш

Основная клавиша-модификатор: **`Super` (Win)**.

### 🪟 Управление окнами
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + Q` | `killclient` | Закрыть активное окно |
| `Alt + Enter` | `togglefullscreen` | Полноэкранный режим |
| `Super + Space` | `togglefloating` | Переключить плавающий / тайловый режим |
| `Super + S` / `Super + Backspace` | `toggle_scratchpad` | Показать / скрыть окно Scratchpad |

### 🧭 Фокус и навигация
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + Стрелки` | `focusdir` | Переместить фокус на соседнее окно по направлению |

### 📐 Перемещение и изменение размера окон
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + Alt + Стрелки` | `exchange_client` | Поменять местами текущее окно с соседним |
| `Super + Shift + Влево` | `setmfact -0.05` | Уменьшить пропорцию мастер-зоны |
| `Super + Shift + Вправо` | `setmfact +0.05` | Увеличить пропорцию мастер-зоны |
| `Super + Shift + Вверх` | `resizewin +0 -20` | Уменьшить высоту окна на 20px |
| `Super + Shift + Вниз` | `resizewin +0 +20` | Увеличить высоту окна на 20px |
| `Super + ЛКМ` (зажать) | `movewin` | Перетаскивание плавающего окна мышью |
| `Super + ПКМ` (зажать) | `resizewin` | Изменение размера плавающего окна мышью |

### 🖥️ Рабочие столы (Воркспейсы 1..10)
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + 1..0` | `workspace <N>` | Переключиться на рабочий стол 1..10 |
| `Super + Shift + 1..0` | `move to workspace <N>` | Переместить окно на рабочий стол 1..10 |
| `Super + Ctrl + Влево/Вверх` | `viewtoleft` | Переключиться на предыдущий рабочий стол |
| `Super + Ctrl + Вправо/Вниз` | `viewtoright` | Переключиться на следующий рабочий стол |

### 🚀 Приложения и оболочка Selion
| Комбинация | Действие |
| :--- | :--- |
| `Super + Enter` | Терминал Kitty |
| `Super + E` | Файловый менеджер Ski |
| `Ctrl + Shift + Esc` / `Ctrl + Alt + Del` | Системный монитор Btop |
| `Super + A` | Меню приложений (лаунчер) |
| `Super + I` | Панель настроек Selion |
| `Super + V` | История буфера обмена |
| `Super + W` | Меню выбора обоев |
| `Super + B` | Скрыть/показать статус-бар |
| `Super + R` | Перезагрузить оболочку Serpantinum |
| `Super + L` | Блокировка экрана |
| `Print` | Скриншот выбранной области |
| `Shift + Print` | Скриншот области с редактором (Satty) |
| `Super + Print` | Скриншот всего экрана |
| `Super + Shift + Print` | Скриншот всего экрана с редактором |
| `Alt + Shift` / `Ctrl + Shift` | Переключение раскладки клавиатуры |
| `Super + Shift + C/Z/S/T/G/D/O` | VS Code, Zen Browser, Spotify, AyuGram, Steam, Discord, Obsidian |
| Мультимедиа-клавиши | Громкость, микрофон, яркость экрана, медиаплеер |

## 💡 Полезные настройки

- Файлы конфигурации Mango находятся в [compositors/mango/default/](file:///media/Drives/Windows-D/Projects/Selion/Selion-dots/compositors/mango/default/).
- Пользовательские переопределения вносите в [compositors/mango/userprefs.conf](file:///media/Drives/Windows-D/Projects/Selion/Selion-dots/compositors/mango/userprefs.conf).
- Изменяя параметр `tag_num` в `general.conf`, можно настраивать количество рабочих столов под свои нужды.
