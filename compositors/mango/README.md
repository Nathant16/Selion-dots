# Mango — Руководство и горячие клавиши

Mango — ультралегкий динамический тайловый Wayland-композитор на базе wlroots, вдохновленный архитектурой dwm. Mango потребляет минимум оперативной памяти и ресурсов процессора, обеспечивая максимальную скорость отклика.

Все базовые системные комбинации (запуск Kitty, Ski, Btop, лаунчера, скриншотов, мультимедиа и переключения раскладки) работают так же, как и в остальных композиторах. Их полный список см. в [общем руководстве по горячим клавишам](../README.md).

---

## Концепция и ключевые особенности

- **Классический динамический тайлинг (Master & Stack):** Экран разделен на главную область (Master — для основной активной задачи) и стек второстепенных окон (Stack).
- **Мгновенный обмен окон (Exchange):** Быстрая перестановка окна в мастер-зону или перемещение по стеку комбинацией `Super + Alt + Стрелки`.
- **Scratchpad:** Всплывающий терминал или блокнот по нажатию `Super + S` или `Super + Backspace`.

## Горячие клавиши Mango

Основная клавиша-модификатор: `Super` (Win).

### Управление окнами
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + Q` | `killclient` | Закрыть активное окно |
| `Alt + Enter` | `togglefullscreen` | Полноэкранный режим |
| `Super + Space` | `togglefloating` | Переключить плавающий / тайловый режим |
| `Super + S` / `Super + Backspace` | `toggle_scratchpad` | Показать / скрыть окно Scratchpad |

### Фокус, обмен местами и изменение размера
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + Стрелки` | `focusdir` | Переместить фокус на соседнее окно по направлению |
| `Super + Alt + Стрелки` | `exchange_client` | Поменять местами текущее окно с соседним |
| `Super + Shift + Влево` | `setmfact -0.05` | Уменьшить пропорцию мастер-зоны |
| `Super + Shift + Вправо` | `setmfact +0.05` | Увеличить пропорцию мастер-зоны |
| `Super + Shift + Вверх` | `resizewin +0 -20` | Уменьшить высоту окна на 20px |
| `Super + Shift + Вниз` | `resizewin +0 +20` | Увеличить высоту окна на 20px |
| `Super + ЛКМ` (зажать) | `movewin` | Перетаскивание плавающего окна мышью |
| `Super + ПКМ` (зажать) | `resizewin` | Изменение размера плавающего окна мышью |

### Рабочие столы (Воркспейсы 1..10)
| Комбинация | Действие | Описание |
| :--- | :--- | :--- |
| `Super + 1..0` | `workspace <N>` | Переключиться на рабочий стол 1..10 |
| `Super + Shift + 1..0` | `move to workspace <N>` | Переместить окно на рабочий стол 1..10 |
| `Super + Ctrl + Влево/Вверх` | `viewtoleft` | Предыдущий рабочий стол |
| `Super + Ctrl + Вправо/Вниз` | `viewtoright` | Следующий рабочий стол |
