# Руководство по горячим клавишам и оконным менеджерам

В Selion реализована сквозная унификация управления: независимо от выбранного композитора (DriftWM, Hyprland, Sway, Niri или Mango), все базовые сочетания клавиш, запуск приложений, системные утилиты, управление мультимедиа и навигация работают одинаково.

Различия между композиторами касаются исключительно их внутренней архитектуры (бесконечный холст, ленточный тайлинг, динамические или ручные сетки).

---

## Единые сочетания клавиш (работают во всех композиторах)

Основная клавиша-модификатор: `Super` (клавиша Windows).

### Приложения и системная оболочка
| Сочетание | Действие | Описание |
| :--- | :--- | :--- |
| `Super + Enter` | Терминал Kitty | Запуск основного эмулятора терминала |
| `Super + E` | Файловый менеджер Ski | Запуск легковесного файлового менеджера |
| `Ctrl + Shift + Esc` | Системный монитор Btop | Мониторинг процессора, памяти, дисков и процессов |
| `Ctrl + Alt + Del` | Системный монитор Btop | Альтернативное сочетание для запуска диспетчера задач |
| `Super + A` | Меню приложений | Открыть/скрыть лаунчер программ |
| `Super + I` | Настройки системы | Открыть центр управления Selion Settings |
| `Super + V` | Буфер обмена | История буфера обмена (Cliphist) |
| `Super + W` | Меню обоев | Быстрый выбор фонового изображения |
| `Super + B` | Автоскрытие панели | Скрыть или закрепить верхнюю статус-панель |
| `Super + R` | Перезагрузка шелла | Перезапуск графической оболочки Serpantinum |
| `Super + L` | Блокировка экрана | Заблокировать сессию (Lockscreen) |
| `PowerOff` | Блокировка экрана | Аппаратная кнопка питания блокирует экран |
| `Alt + Shift` (в любом порядке) | Смена раскладки | Переключение языка ввода (US / RU) |

### Быстрый запуск программ
| Сочетание | Приложение |
| :--- | :--- |
| `Super + Shift + C` | VS Code (Редактор кода) |
| `Super + Shift + Z` | Zen Browser (Веб-браузер) |
| `Super + Shift + S` | Spotify (Музыкальный плеер) |
| `Super + Shift + T` | AyuGram / Telegram (Мессенджер) |
| `Super + Shift + G` | Steam (Игровая платформа) |
| `Super + Shift + D` | Discord (Голосовой и текстовый чат) |
| `Super + Shift + O` | Obsidian (Заметки и база знаний) |

### Снимки экрана (Скриншоты)
| Сочетание | Режим снимка |
| :--- | :--- |
| `Print` | Снимок выбранной прямоугольной области в буфер и файл |
| `Shift + Print` | Снимок области с мгновенным открытием в редакторе Satty |
| `Super + Print` | Снимок всего экрана |
| `Super + Shift + Print` | Снимок всего экрана с открытием в редакторе Satty |

### Мультимедиа и аппаратные клавиши
| Сочетание | Функция |
| :--- | :--- |
| `XF86AudioRaiseVolume` | Увеличить громкость звука |
| `XF86AudioLowerVolume` | Уменьшить громкость звука |
| `XF86AudioMute` | Включить/выключить звук динамиков |
| `XF86AudioMicMute` | Включить/выключить микрофон |
| `XF86AudioPlay` / `Pause` | Воспроизведение / Пауза медиаплеера |
| `XF86AudioNext` | Следующий трек |
| `XF86AudioPrev` | Предыдущий трек |
| `XF86MonBrightnessUp` | Увеличить яркость подсветки экрана |
| `XF86MonBrightnessDown` | Уменьшить яркость подсветки экрана |

### Базовые действия с окнами
| Сочетание | Действие | Поведение |
| :--- | :--- | :--- |
| `Super + Q` | Закрыть окно | Завершение активного окна приложения |
| `Alt + Enter` | Полный экран | Переключение полноэкранного режима |
| `Super + Space` | Плавающий режим | Переключение между тайловым и плавающим окном |
| `Super + Стрелки` | Смена фокуса | Перемещение фокуса на соседнее окно по направлению |
| `Alt + Tab` | Следующее окно | Циклическое переключение фокуса вперед |
| `Super + Alt + Стрелки` | Перемещение окна | Сдвиг окна в сетке, обмен местами или снаппинг |

### Рабочие столы (Воркспейсы 1..10)
| Сочетание | Действие |
| :--- | :--- |
| `Super + 1..0` | Перейти на рабочий стол 1..10 |
| `Super + Shift + 1..0` | Переместить активное окно на рабочий стол 1..10 |
| `Super + Ctrl + Влево/Вправо` | Перейти на предыдущий / следующий рабочий стол |

## Архитектурные различия и уникальные функции

В таблице ниже приведены различия в логике и специфические комбинации для каждого композитора:

| Функция / Механика | DriftWM | Hyprland | Sway | Niri | Mango |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Основная концепция** | Бесконечный 2D-холст (Figma/Miro) | Динамический тайлинг Dwindle/Master | Ручной тайлинг по дереву контейнеров i3 | Горизонтальная бесконечная лента колонок | Легковесный Master & Stack (стиль dwm) |
| **Изменение размера окон** (`Super + Shift + Стрелки`) | `grow-window` / `shrink-window` (по сторонам) | Плавный шаг на 40px | Шаг на 5% (5 ppt) | Ширина колонки / высота окна на 5% | Соотношение Master-зоны `setmfact` / высота |
| **Карман (Scratchpad)** | Не используется (окна живут на холсте) | `Super + S` (показ), `Super + Alt + S` (отправка) | `Super + S` (показ), `Super + Alt + S` (отправка) | `Super + S` / `Super + Backspace` — Режим Overview | `Super + S` / `Super + Backspace` (показ) |
| **Заморозка окон** | `Super + Shift + Q` (`suspend-window`) | Не поддерживается | Не поддерживается | Не поддерживается | Не поддерживается |
| **Масштабирование (Зум)** | `Super + =` (вход), `Super + -` (выход), `Super + 0` (сброс) | Не поддерживается | Не поддерживается | Не поддерживается | Не поддерживается |
| **Возврат в центр (0,0)** | `Super + Home` / `Super + ~` | Не требуется | Не требуется | Не требуется | Не требуется |
| **Закрепление на стекле (HUD)** | `Super + T` / `Super + Space` (`pinned_to_screen`) | `Super + Space` (плавающее окно) | `Super + Space` (плавающее окно) | `Super + Space` (плавающее окно) | `Super + Space` (плавающее окно) |
| **Жесты тачпада** | 2 пальца: панорамирование и щипок зума (Pinch) | 3 пальца: плавный 1:1 свайп рабочих столов | 3 пальца: свайп столов влево/вправо, лаунчер вверх | 2 пальца: горизонтальная прокрутка ленты окон | Базовый клик и тап |

## Подробные руководства по композиторам

- [DriftWM — Руководство](driftwm/README.md): управление бесконечным холстом, радар-карта, закладки, снаппинг и зум.
- [Hyprland — Руководство](hyprland/README.md): анимации, физический свайп рабочих столов, плавающий режим и Scratchpad.
- [Sway — Руководство](sway/README.md): классическое дерево контейнеров i3, трекпад-жесты и режим Clamshell.
- [Niri — Руководство](niri/README.md): ленточный скроллинг колонок, режим Overview и вертикальные столы.
- [Mango — Руководство](mango/README.md): ультралегкий динамический тайлинг, обмен клиентов и быстрый отклик.
